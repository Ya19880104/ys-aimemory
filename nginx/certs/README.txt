Operator supplies fullchain.pem and privkey.pem here before using --profile tls.
The certificate SAN must match the hostname Windows clients use. Install your
private CA trust on those clients through your normal administration process.
Do not disable certificate validation. Never commit certificate private keys.
The nginx container runs as UID/GID 101. Provision narrowly scoped read access
for that identity; do not make the private key world-readable. No certificates
or persistent credentials are generated by this project.
